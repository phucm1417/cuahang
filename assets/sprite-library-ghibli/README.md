# Sprite library — cozy illustrated variant

Independent redesign of the project catalog: 40 food and drink sprites plus 20 restaurant props. The original assets remain untouched.

- `index.html`: visual gallery for review
- `catalog.json` / `catalog.js`: names and relative asset paths
- `food/`: food and drink SVG files
- `props/`: restaurant item SVG files

The drawings retain the source silhouettes and palette, with softened outlines and light shadow treatment for a warmer illustrated look. SVGs keep transparent backgrounds and can be edited or integrated into the game.
